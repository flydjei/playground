Toolbox

작업하다 자주 찾게 되는 작은 도구 모음입니다. 붙여넣고, 바꾸고, 복사하면 끝납니다.

  • 서브넷 IP 계산기

    CIDR 서브넷과 IP 범위를 개별 IP 목록으로 펼칩니다. 중복 제거와 정렬, 네트워크/브로드캐스트 주소 제외를 지원합니다.

    10.0.0.0/30
    → 
    10.0.0.0
10.0.0.1
10.0.0.2
10.0.0.3

  • IP 추출기

    텍스트에 섞인 IPv4 주소만 골라냅니다. 줄 번호를 그대로 두거나 IP만 모아 볼 수 있습니다.

    web01 10.0.0.1
점검 메모
db 10.0.0.9 확인
    → 
    10.0.0.1

10.0.0.9

  • 특수문자표

    한글 자음을 쓰고 한자 키를 누르면 나오는 특수문자 전체 목록입니다. 명칭이나 코드로 찾고, 누르면 복사됩니다.

    ㅁ + 한자 → ★※☆◆♣

모든 도구는 브라우저 안에서만 동작합니다. 입력한 내용은 어디에도 전송되지 않습니다.
