Toolbox

자주 쓰는 작은 도구 모음입니다. 모두 브라우저 안에서만 동작하며 입력한 내용은 어디에도 전송되지 않습니다.

  • 서브넷 IP 계산기

    CIDR 서브넷과 IP 범위를 개별 IP 목록으로 펼칩니다. 중복 제거·정렬, 네트워크/브로드캐스트 주소 제외를 지원합니다.

  • IP 추출기

    텍스트에 섞인 IPv4 주소만 골라냅니다. 줄 번호를 유지하거나 IP만 모아 볼 수 있습니다.

  • 특수문자표

    한글 자음 + 한자 키로 입력하는 특수문자 전체 목록입니다. 명칭·코드로 검색하고 클릭해서 복사합니다.
